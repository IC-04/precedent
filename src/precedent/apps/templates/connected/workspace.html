{% elif page == 'setup' %}

One-time developer setup

Connect your test accounts.

Google and Slack each require a registered app. Vertex AI credentials already used by Ava do not authorize access to email.

01 · Gmail

Enable Gmail API in your Google Cloud project. Create a Web application OAuth client and an External consent screen in Testing. Add your dedicated test account. Request only gmail.readonly.

Register http://localhost:8127/oauth/gmail/callback as the redirect URI when using the default local ports.

Set PRECEDENT_GMAIL_CLIENT_ID, PRECEDENT_GMAIL_CLIENT_SECRET and PRECEDENT_GMAIL_REDIRECT_URI in your local environment. Restart this workspace, then Connect. Test grants expire after seven days.

02 · Slack

Create an app in a dedicated test workspace. Add user scopes channels:read and channels:history. Use the delegated user grant; no posting permission is needed.

Register an HTTPS redirect ending in /oauth/slack/callback. Forward only the callback listener on port 8127 through an authorized HTTPS endpoint. The workspace on 8126 must stay private.

Set PRECEDENT_SLACK_CLIENT_ID, PRECEDENT_SLACK_CLIENT_SECRET and PRECEDENT_SLACK_REDIRECT_URI, restart, then Connect.

03 · Choose and try

Choose one Gmail label, up to two public Slack channels, and a recent time window. Use synthetic conversations about the same topic. Open the workspace, review the sources, and give Ava a preparation task.
